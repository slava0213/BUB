# 🚗 Сервис поиска попутчиков

Веб-приложение: поездки, заявки, живой чат, отзывы и рейтинг водителей.

## 🛠 Стек
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)
- **Backend:** Node.js + Express
- **Авторизация:** JWT (httpOnly cookie) + bcrypt
- **Хранилище:** JSON-файл `server/carpool.json`

## ✏️ Ваши контакты
Откройте `client/js/config.js` и впишите имя, Telegram, e-mail и телефон —
они появятся в бегущей строке и в подвале каждой страницы.

## 🚀 Локальный запуск
```bash
cd server
npm install
npm start
```
Откройте http://localhost:3000

При первом запуске создаются демо-поездки (помечены «демо»).
Отключить: переменная окружения `SEED_DEMO=0`.

## 🌐 Деплой на Render
1. На https://render.com → **New → Web Service** → выберите репозиторий.
2. Root Directory: `server` · Build: `npm install` · Start: `npm start`
3. Environment: `JWT_SECRET` = длинная случайная строка.
(Либо **New → Blueprint** — настройки возьмутся из `render.yaml`.)

> GitHub Pages не подойдёт: нужен Node.js-сервер.
> На бесплатном Render файловая система временная — данные сбрасываются при перезапуске.

## 📍 Отслеживание водителя (новое)

- В карточке своей поездки водитель открывает **«GPS»**, затем нажимает **«Включить передачу GPS»** и разрешает доступ к геолокации.
- Пассажир открывает ссылку **«Где водитель?»** после того, как водитель подтвердил его заявку.
- Карта обновляется примерно раз в 10 секунд. Маршрут и ETA строятся по дорогам через OpenStreetMap / OSRM.
- GPS работает только по HTTPS (или на `localhost`). На телефоне браузеру нужно разрешить геолокацию; вкладка с сайтом должна оставаться открытой.
- Доступ к координатам ограничен водителем и пассажирами с принятой заявкой. Координаты не сохраняются в постоянной базе: при перезапуске сервера активная точка сбрасывается.
- ETA рассчитывается до географического центра города назначения, поскольку текущая модель поездки хранит города, а не точные адреса. Это ориентировочная оценка, а не гарантированное время прибытия.

Для реальной эксплуатации рекомендуется подключить собственный маршрутизатор/геокодер с соблюдением лимитов провайдеров и хранить координаты с ограниченным сроком жизни.
