# 🚗 Сервис поиска попутчиков

Веб-приложение: поездки, заявки, живой чат, отзывы и рейтинг водителей.

## 🛠 Стек
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)
- **Backend:** Node.js + Express
- **Авторизация:** JWT (httpOnly cookie) + bcrypt
- **Хранилище:** JSON-файл `server/carpool.json`

## ✏️ Ваши контакты
Откройте `client/js/config.js` и впишите имя, Telegram, e-mail и телефон —
они появятся в бегущей строке и в подвале каждой страницы.

## 🚀 Локальный запуск
```bash
cd server
npm install
npm start
```
Откройте http://localhost:3000

При первом запуске создаются демо-поездки (помечены «демо»).
Отключить: переменная окружения `SEED_DEMO=0`.

## 🌐 Деплой на Render
1. На https://render.com → **New → Web Service** → выберите репозиторий.
2. Root Directory: `server` · Build: `npm install` · Start: `npm start`
3. Environment: `JWT_SECRET` = длинная случайная строка.
(Либо **New → Blueprint** — настройки возьмутся из `render.yaml`.)

> GitHub Pages не подойдёт: нужен Node.js-сервер.
> На бесплатном Render файловая система временная — данные сбрасываются при перезапуске.

## Отслеживание поездки (новое)

Страница `track.html?trip=ID` показывает на карте, где сейчас водитель, и считает, когда он приедет.

- Водитель нажимает «Начать поездку» — браузер передаёт геопозицию (нужен HTTPS или localhost).
- Пассажир с **принятой** заявкой видит водителя, время прибытия в пункт назначения и до своей точки посадки (её можно отметить на карте или по геопозиции).
- Время считается через OSRM по дорогам, без пробок. Если сервис недоступен, используется оценка по прямой (помечается как ориентировочная).
- Для показа без выезда есть кнопка «Симуляция» (ускорение ×30 / ×60 / ×120).
- Координаты городов: встроенный справочник, затем Nominatim. Для старых поездок определяются автоматически при первом открытии карты.
- Позиция хранится только в памяти сервера и удаляется при завершении поездки.

API: `POST /api/trips/:id/start | finish | location | pickup`, `GET /api/trips/:id/tracking`.

## Оформление

Страницы по требованиям: Поездки (`index.html`), Создать поездку, Поиск, Чат, Профиль (плюс вход и регистрация).
Дизайн в духе макета такси: баннер, круглое меню, жёлтые карточки слева (быстрый поиск, популярные направления), блок «Автомобили наших водителей» (машины рисуются в `js/cars.js`), центрированное меню в подвале.
Данные временно хранятся в JSON (`server/carpool.json`), позже планируется БД.
